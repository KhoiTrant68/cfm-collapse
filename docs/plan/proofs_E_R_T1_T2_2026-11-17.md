STATEMENT (Proposition E). Let 0 < σ_min < σ_max. D : R^d × [σ_min, σ_max] → R^d is continuous, C^1 in x, with J = ∂_x D jointly continuous. x : [σ_min, σ_max] → R^d is a C^1 solution of dx/dσ = (x − D(x,σ))/σ (sampling integrates from σ_max down to σ_min). Fix y ∈ R^d, e = x − y, b(σ) = D(y,σ) − y, and assume e(σ) ≠ 0 on the interval. ê = e/|e|, q(σ) = ∫_0^1 êᵀ J(y+τe, σ) ê dτ, Φ(a,s) = exp(−∫_a^s (1 − q(u))/u du).
(a) |e(σ_min)| = Φ(σ_min,σ_max)|e(σ_max)| + ∫_{σ_min}^{σ_max} Φ(σ_min,s) ê(s)·b(s)/s ds.
(b) With Λ⁻, Λ⁺ the inf/sup over the segment {y+τe} of λ_min, λ_max of sym J, and Φ^± defined with Λ^± in place of q: Λ⁻ ≤ q ≤ Λ⁺ and
  Φ⁻(σ_min,σ_max)|e(σ_max)| − ∫ Φ⁺(σ_min,s)|b|/s ds ≤ |e(σ_min)| ≤ Φ⁺(σ_min,σ_max)|e(σ_max)| + ∫ Φ⁺(σ_min,s)|b|/s ds.
  λ_max alone does not determine the shrinkage (example below).
(c) For σ_min < σ_a ≤ σ_max, ρ̄ = sup_{[σ_min,σ_a]}(1 − q), β = sup_{[σ_min,σ_a]}|b|:
  |e(σ_a)| ≤ (σ_a/σ_min)^{ρ̄}|e(σ_min)| + β g(ρ̄), g(ρ̄) = ((σ_a/σ_min)^{ρ̄} − 1)/ρ̄ (ρ̄ ≠ 0), g(0) = log(σ_a/σ_min).
(d) For y_1, y_2 with e_k = x − y_k ≠ 0 and r = |e_1|/|e_2|:
  log r(σ_min) − log r(σ_max) = ∫_{σ_min}^{σ_max} (q_1 − q_2)(s)/s ds + ∫_{σ_min}^{σ_max} [ê_1·b_1/|e_1| − ê_2·b_2/|e_2|](s)/s ds.

Regularity. x is C^1 and e ≠ 0, so ê is continuous and n := |e| is C^1 with n' = ê·e'. The integrand of q is jointly continuous on the compact [0,1]×[σ_min,σ_max], so q is continuous; b is continuous. Hence p := (1 − q)/σ is continuous, Φ(a,·) is C^1, positive, ∂_sΦ(a,s) = −p(s)Φ(a,s), Φ(a,a) = 1.

  n' = (1 − q) n/σ − ê·b/σ.     (★)

(a) Let F(s) = Φ(σ_min,s) n(s). By (★), F' = Φ(−p n + n') = −Φ(σ_min,s) ê·b/s. Integrating over [σ_min,σ_max] and using F(σ_min) = n(σ_min) gives (a). The same argument works on any subinterval [a, σ']: n(a) = Φ(a,σ')n(σ') + ∫_a^{σ'} Φ(a,s) ê·b/s ds.
Sign check: D = a x, y = 0 gives b = 0 and n(σ_min) = exp(−∫(1−a)/u du) n(σ_max), the exact solution. D ≡ 0, d = 1, x = cσ (c > 0), y < 0: q = 0, b = −y = |y|, ê = +1; the formula gives (σ_min/σ_max)(cσ_max + |y|) + ∫ (σ_min/s)|y|/s ds = cσ_min + |y| = n(σ_min). Correct.

(b) For a unit vector v, vᵀJv = vᵀ(sym J)v ∈ [λ_min, λ_max] (Rayleigh). Integrating over τ gives Λ⁻ ≤ q ≤ Λ⁺. Λ^± are continuous in σ (eigenvalue extremes are continuous in the matrix entries (Weyl); the map (τ,σ) ↦ λ(sym J(y+τe(σ),σ)) is jointly continuous; inf/sup over compact τ-set preserves continuity), so Φ^± are well defined. From 1 − Λ⁺ ≤ 1 − q ≤ 1 − Λ⁻: 0 < Φ⁻ ≤ Φ ≤ Φ⁺. With −|b| ≤ ê·b ≤ |b| and Φ > 0: the upper bound follows from Φ ≤ Φ⁺ in both terms; the lower bound from Φ ≥ Φ⁻ in the first term and Φ ê·b ≥ −Φ|b| ≥ −Φ⁺|b| in the second.
Example. d = 2, D(x) = Ax, A = diag(1, 1 − m), m > 0, y = 0, b = 0, sym J = A, λ_max ≡ 1, κ = σ_max/σ_min. x_i' = (1 − λ_i)x_i/σ. Start (0,1): n(σ_min) = κ^{−m}, while the λ_max upper bound gives 1. Tight when b = 0 and D = a x, y = 0.

(d) For each k, n_k > 0 is C^1 and by (★) (log n_k)' = (1 − q_k)/σ − ê_k·b_k/(σ n_k). Subtract, integrate over [σ_min, σ_max], and use log r(σ_min) − log r(σ_max) = −∫ (log r)' ds. This gives (d). Example: A = diag(1, 1 − m), y_1 = 0, y_2 = (c, 0), c ≠ 0, start (0, h): b_1 = b_2 = 0, x_2 = h(σ/σ_max)^m, q_1 = 1 − m, q_2 = 1 − m x_2²/(c² + x_2²); (d) predicts −m ∫ c²/(c²+x_2²) ds/s, and direct differentiation of log r = log|x_2| − ½ log(c² + x_2²) confirms it, while λ_max(sym J) = 1 at every point for both anchors.

STATEMENT (Lemma R). x^1, …, x^N ∈ R^d distinct, N ≥ 2, Δ = max_{j,k}|x^j − x^k|, D_j = max_k |x^j − x^k|. For y ∈ R^d, σ > 0: w_j(y) = exp(−|y − x^j|²/(2σ²)) / Σ_k exp(−|y − x^k|²/(2σ²)), m(y) = Σ_j w_j x^j. For v ∈ R^d: e(v) = |v − m(y)|, n(v) = min_j |v − x^j|.
(a) n(v) − (1 − w_max) D_i ≤ e(v) ≤ n(v) + (1 − w_{j*}) D_{j*}, with i an argmax of w and j* any index with |v − x^{j*}| = n(v). In particular with Δ in place of D_i, D_{j*}. The constant is sharp (cannot be replaced by cΔ, c < 1).
(b) If δ_i(y) = min_{k≠i}|y − x^k| and |y − x^i| ≤ ρ δ_i(y), 0 ≤ ρ < 1, then 1 − w_i(y) ≤ (N − 1) exp(−(1 − ρ²) δ_i(y)²/(2σ²)).
(c) Finite groups O, A with scores s, s', |s(z) − s'(z)| ≤ ε for all z; AUC(s) = (1/(|O||A|)) Σ_{a∈O,b∈A} H(s(a) − s(b)), H(t) = 1{t>0} + ½1{t=0}. Then |AUC(s) − AUC(s')| ≤ #{(a,b) ∈ O×A : |s'(a) − s'(b)| ≤ 2ε}/(|O||A|).
(d) Fix σ. Each sample z has (y_z, v_z) and an index i(z) with |y_z − x^{i(z)}| ≤ ρ δ_{i(z)}(y_z), ρ < 1. Let δ = min_z δ_{i(z)}(y_z), η = (N − 1)Δ exp(−(1 − ρ²)δ²/(2σ²)).
  (d1) Unconditionally, with d_i(z) := |v_z − x^{i(z)}|: |e(z) − d_i(z)| ≤ η, so |AUC(e) − AUC(d_i)| ≤ fraction of O×A pairs with |d_i(a) − d_i(b)| ≤ 2η.
  (d2) Under (H): x^{i(z)} is a nearest training image of v_z for every z (sufficient: |v_z − x^{i(z)}| ≤ ½ min_{k≠i(z)} |x^{i(z)} − x^k|), d_i = n and |AUC(e) − AUC(n)| ≤ fraction of pairs with |n(a) − n(b)| ≤ 2η.
  (d3) Without (H) the n-version is false.

PROOF.
Key lemma. Since Σ_k w_k = 1, m − x^j = Σ_{k≠j} w_k (x^k − x^j), so |m − x^j| ≤ Σ_{k≠j} w_k |x^k − x^j| ≤ (1 − w_j) D_j ≤ (1 − w_j)Δ.
(a) Upper: e ≤ |v − x^{j*}| + |x^{j*} − m| ≤ n + (1 − w_{j*}) D_{j*}. Lower: n ≤ |v − x^i| ≤ |v − m| + |m − x^i| ≤ e + (1 − w_max) D_i.
Sharpness: N = 2, x^1 = 0, x^2 = Δu, |u| = 1, m = w_2 Δu (w_1 takes every value in (0,1) as y moves along u). Upper: v = −tu, t ≥ 0: j* = 1, n = t, e = t + w_2Δ = n + (1 − w_{j*})Δ. Lower: w_1 ≥ ½ (so w_max = w_1), v = m: e = 0, n = min(w_2Δ, w_1Δ) = w_2Δ = (1 − w_max)Δ.
(b) For k ≠ i, w_k = w_i exp((|y − x^i|² − |y − x^k|²)/(2σ²)) ≤ exp(−(1 − ρ²)δ_i²/(2σ²)), using w_i ≤ 1, |y − x^i|² ≤ ρ²δ_i², |y − x^k|² ≥ δ_i². Sum the N − 1 terms: 1 − w_i = Σ_{k≠i} w_k. (δ_i > 0 by distinctness.)
(c) For a pair, t = s(a) − s(b), t' = s'(a) − s'(b), |t − t'| ≤ 2ε. If t' > 2ε then t > 0 and H(t) = H(t') = 1; if t' < −2ε then t < 0 and both are 0; otherwise |H(t) − H(t')| ≤ 1. Sum over pairs.
(d1) Key lemma with j = i(z): |e(z) − d_i(z)| ≤ |m(y_z) − x^{i(z)}| ≤ (1 − w_{i(z)})Δ ≤ (N − 1)Δ exp(−(1 − ρ²)δ_{i(z)}²/(2σ²)) ≤ η (by (b) and δ ≤ δ_{i(z)}, t ↦ e^{−ct²} decreasing). Apply (c) with s = e, s' = d_i, ε = η.
(d2) Under (H), d_i(z) = n(v_z); apply (d1). Sufficient condition: if r := |v − x^i| ≤ ½ g_i, g_i = min_{k≠i}|x^i − x^k|, then |v − x^k| ≥ g_i − r ≥ r for k ≠ i.
(d3) Counterexample: d = 1, x^1 = 0, x^2 = 1, O = {a}, A = {b}, y_a = y_b = 0 (ρ = 0, δ = 1), v_a = 1, v_b = 0.3. n(a) = 0 < n(b) = 0.3, so AUC(n) = 0; m(0) = 1/(1 + e^{1/(2σ²)}) → 0, so e(a) ≈ 1 > e(b) ≈ 0.3, AUC(e) = 1; for small σ, 2η < 0.3 and the pair-fraction bound is 0.

STATEMENT (Theorem T1). 0 ≤ t₁ < 1, ε_t = 1 − t. x̂ : R^d × [t₁,1) → R^d continuous; Z : [t₁,1) → R^d C¹ with Z' = (x̂(Z,t) − Z)/ε. x¹,…,x^N distinct (N ≥ 1); w_j : R^d × [t₁,1) → [0,1] continuous, Σ_j w_j ≡ 1; m*(z,t) = Σ_j w_j x^j. Fix i; e = Z − x^i, n = |e|, D_i = max_k |x^i − x^k|, err(t) = |x̂(Z_t,t) − m*(Z_t,t)|, ω(t) = (1 − w_i(Z_t,t)) D_i.
(a) n is locally Lipschitz; where e ≠ 0, n' = (⟨ê, x̂ − x^i⟩ − n)/ε; for a.e. t, n' ≤ (err + ω − n)/ε.
(b) If err ≤ ϱ̄ n + γ with constant ϱ̄ < 1 and continuous γ ≥ 0, η := γ + ω, then n_t ≤ (ε_t/ε_{t₁})^{1−ϱ̄} n_{t₁} + ∫_{t₁}^t (η(s)/ε_s)(ε_t/ε_s)^{1−ϱ̄} ds, and η(t) → 0 implies Z_t → x^i.
(c) If n_{t₁} > 0, δ continuous, ⟨ê, x̂(Z,t) − x^i⟩ ≥ (1 − δ)n whenever n > 0, and ∫_{t₁}^1 δ⁺/ε < ∞, then n_t ≥ n_{t₁} exp(−∫_{t₁}^t δ⁺/ε) > 0 for all t (Z does not converge to x^i), and err ≥ (1 − δ)n − ω.
(d) The threshold ϱ̄ < 1 in (b) is sharp.

PROOF.
Lemma. Σ w_j = 1 gives m* − x^i = Σ_{j≠i} w_j (x^j − x^i), so |m* − x^i| ≤ (1 − w_i) D_i.
(a) e is C¹, so on [t₁,T] (T < 1) |e'| ≤ M_T and |n(t) − n(s)| ≤ |e(t) − e(s)| ≤ M_T|t − s|. Where e ≠ 0 the norm is smooth with gradient ê, and e' = (x̂ − x^i − e)/ε, so n' = (⟨ê, x̂ − x^i⟩ − n)/ε; by Cauchy–Schwarz and the Lemma ⟨ê, x̂ − x^i⟩ ≤ |x̂ − m*| + |m* − x^i| ≤ err + ω. At a point t > t₁ with e_t = 0 where n is differentiable, n has a minimum (n ≥ 0 = n_t), so n'(t) = 0 ≤ (err + ω)/ε. n is differentiable a.e. (Lipschitz), so the inequality holds a.e.
(b) Let a = 1 − ϱ̄ > 0. A.e., n' ≤ (−a n + η)/ε. u = ε^{−a} n is locally Lipschitz (product with a C¹ factor), hence absolutely continuous on [t₁,t], and a.e. u' = a ε^{−a−1} n + ε^{−a} n' ≤ ε^{−a−1} η. η is continuous. Integrating (FTC for AC functions) and multiplying by ε_t^a gives the bound. Landing: fix κ > 0, choose τ with η ≤ κ on [τ,1). The first term → 0; the integral over [t₁,τ] equals ε_t^a C_τ → 0; the integral over [τ,t] is ≤ κ ε_t^a (ε_t^{−a} − ε_τ^{−a})/a ≤ κ/a. So limsup n ≤ κ/a for all κ, i.e. n → 0.
(c) Let T = sup{s : n > 0 on [t₁,s]} > t₁. On [t₁,T), e ≠ 0, n is C¹ and n' ≥ ((1 − δ)n − n)/ε ≥ −δ⁺ n/ε, so (log n)' ≥ −δ⁺/ε and n_t ≥ n_{t₁} exp(−∫_{t₁}^t δ⁺/ε) ≥ n_{t₁} e^{−I}, I = ∫_{t₁}^1 δ⁺/ε < ∞. If T < 1, continuity gives n_T ≥ n_{t₁}e^{−I} > 0, so n > 0 slightly beyond T, contradicting the definition of T. Hence T = 1, the bound holds for all t, and liminf n ≥ n_{t₁}e^{−I} > 0. Finally (1 − δ)n ≤ ⟨ê, x̂ − x^i⟩ ≤ err + ω.
(d) N = 1 (m* ≡ x¹, ω ≡ 0), x̂(z,t) = x¹ + ϱ(z − x¹), ϱ ≥ 0: err = ϱ n, e' = −(1 − ϱ) e/ε, and d/dt(ε^{−(1−ϱ)} e) = 0, so e_t = e_{t₁}(ε_t/ε_{t₁})^{1−ϱ}. With e_{t₁} ≠ 0: n → 0 if ϱ < 1, n constant if ϱ = 1, n → ∞ if ϱ > 1. At ϱ = 1 the hypothesis of (b) holds with ϱ̄ = 1, γ = 0, and landing fails.

STATEMENT (Theorem T2). x¹,…,x^N ∈ R^d distinct, N ≥ 2. For σ > 0, w_j(x,σ) = exp(−|x − x^j|²/(2σ²)) / Σ_k exp(−|x − x^k|²/(2σ²)), m*(x,σ) = Σ_j w_j x^j. D : R^d × (0,σ₁] → R^d continuous; x : (0,σ₁] → R^d C¹ with dx/dσ = (x − D(x,σ))/σ (sampling runs from σ₁ down to 0). Fix i; g = min_{k≠i}|x^i − x^k|, D_i = max_k |x^i − x^k|, n(σ) = |x(σ) − x^i|, err(σ) = |D(x(σ),σ) − m*(x(σ),σ)|. Hypotheses, with ϱ̄ ∈ [0,1), γ : (0,σ₁] → [0,∞) continuous, 0 < r ≤ g/4, ρ = r/(g − r), Ω(σ) = (N − 1) D_i exp(−(1 − ρ²)(g − r)²/(2σ²)):
 (H1) err(σ) ≤ ϱ̄ n(σ) + γ(σ) whenever n(σ) ≤ r; (H2) n(σ₁) < r; (H3) γ(σ) + Ω(σ) < (1 − ϱ̄) r for all σ ∈ (0,σ₁].
(i) If |x − x^i| ≤ r then 1 − w_i(x,σ) ≤ (N − 1) exp(−(1 − ρ²)(g − r)²/(2σ²)); ρ ≤ 1/3.
(ii) n(σ) < r for every σ ∈ (0,σ₁].
(iii) n(σ) ≤ (σ/σ₁)^{1−ϱ̄} n(σ₁) + ∫_σ^{σ₁} ((γ(s) + Ω(s))/s)(σ/s)^{1−ϱ̄} ds; if γ(σ) → 0 then x(σ) → x^i.
(iv) For ϱ̄ < 1, r ≤ g/4 there is σ* > 0 with Ω(σ) < (1 − ϱ̄) r/2 for all σ ≤ σ*.

PROOF. a := 1 − ϱ̄ > 0, h := γ + Ω (continuous).
Fact A. |m* − x^i| = |Σ_{j≠i} w_j (x^j − x^i)| ≤ (1 − w_i) D_i.
Fact B. On [σ₀,σ₁], |x'| ≤ L, so |n(a) − n(b)| ≤ L|a − b|: n is locally Lipschitz, hence AC on compacts. Where x ≠ x^i, n' = ⟨ê, x'⟩ = (n − ⟨ê, D − x^i⟩)/σ.
(i) Let |x − x^i| = t ≤ r and k ≠ i: |x − x^k| ≥ g − t ≥ g − r > 0, and w_k ≤ w_k/w_i = exp((t² − |x − x^k|²)/(2σ²)) ≤ exp((r² − (g − r)²)/(2σ²)) = exp(−(1 − ρ²)(g − r)²/(2σ²)) since r = ρ(g − r). Sum over k ≠ i. r ↦ r/(g − r) is increasing, so ρ ≤ (g/4)/(3g/4) = 1/3.
Key inequality. If 0 < n(σ) ≤ r: ⟨ê, D − x^i⟩ ≤ |D − m*| + |m* − x^i| ≤ ϱ̄ n + γ + Ω (H1, Fact A, (i)), so (★) n'(σ) ≥ (a n − h)/σ.
(ii) Suppose S = {σ ∈ (0,σ₁] : n(σ) ≥ r} ≠ ∅, σ̄ = sup S > 0. By (H2) and continuity n < r near σ₁, so σ̄ < σ₁; by continuity n(σ̄) ≥ r and, since n < r on (σ̄,σ₁], n(σ̄) = r > 0. (★) and (H3): n'(σ̄) ≥ (a r − h(σ̄))/σ̄ > 0. But n(σ) < n(σ̄) for σ ∈ (σ̄,σ₁], so the right difference quotients are negative and n'(σ̄) ≤ 0. Contradiction.
(iii) By (ii), n < r everywhere. Fix σ. On [σ,σ₁], a.e. n' ≥ (a n − h)/s: at points with n > 0 by (★); at interior points with n = 0 where n is differentiable, n has a minimum so n' = 0 ≥ −h/s. φ(s) = n(s) s^{−a} is AC on [σ,σ₁] and a.e. φ' = s^{−a}(n' − a n/s) ≥ −h s^{−a−1}. Integrate: φ(σ₁) − φ(σ) ≥ −∫_σ^{σ₁} h s^{−a−1} ds; multiply by σ^a. Convergence: Ω(s) → 0 as s → 0; with γ → 0, h → 0. Given κ, pick δ with h ≤ κ on (0,δ]; for σ < δ the integral over [σ,δ] is ≤ κ σ^a(σ^{−a} − δ^{−a})/a ≤ κ/a, the integral over [δ,σ₁] is σ^a C_δ → 0, and the first term → 0. So limsup n ≤ κ/a for all κ.
(iv) Ω is increasing in σ and → 0 as σ → 0 (since 1 − ρ² > 0). Let q = (1 − ϱ̄) r/(2(N − 1) D_i) ≤ r/(2D_i) ≤ 1/8 (r ≤ g/4 ≤ D_i/4), and σ* = ((1 − ρ²)(g − r)²/(4 log(1/q)))^{1/2}. For σ ≤ σ*, (1 − ρ²)(g − r)²/(2σ²) ≥ 2 log(1/q) > log(1/q), so Ω(σ) < (N − 1) D_i q = (1 − ϱ̄) r/2.
Necessity remarks (not part of the claim): ϱ̄ < 1 is needed (D = x^i + λ(x − x^i), λ ≥ 1, does not land); γ → 0 is needed for exact landing (D = x^i + v gives x → x^i + v); r < g/2 is needed for (i).
