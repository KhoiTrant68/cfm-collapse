## 7. Which statistics use endpoint information

| statistic | endpoint information | note |
|---|---|---|
| off-atom label (learned d1/d2 >= 1/3 at 1-T = 1e-4) | yes (it is the target) | every AUC, TPR and FPR is computed against it; unavoidable for evaluation |
| final scaled error e(t = 0.9999) and its AUC (0.985 / 0.977) | yes | equals the endpoint's d1 within 0.2% for every sample; the label is d1/d2, so this AUC is the AUC of the label's numerator (bookkeeping, as the paper says) |
| rule 'final scaled error > 4' (94/95% TPR, 7/12% FPR) | yes, and the threshold was chosen in sample | it is the rule 'd1 > 4' on the endpoint; it is not an early warning |
| e_learned(t) for grid t < 1 and its AUC | no (score); label yes | the score uses only x_t, the network and m*(x_t) (training set and bandwidth); an online audit statistic, though it needs a sum over the training set at every step |
| e_exact(t) (network error on the exact path) and its AUC | no (score); label yes | needs the exact trajectory from the same source, integrated separately; no learned-endpoint information |
| thresholds selected on other runs (h4->h6, h6->h4, leave-one-seed-out) | labels of the training runs only | out of sample for the test runs; h4->h6 and h6->h4 share conditions and sources seed by seed, leave-one-seed-out at both h does not |
| earliest t with AUC >= 0.95 | score at t only; label yes; t selected post hoc | the selection over t is made on the evaluated data; the bootstrap CI repeats the selection in every replicate |
| within-condition AUC | no (score); label yes | removes between-condition differences |
| condition-prior baseline (share of the other 15 sources of the condition that end off-atom) | yes (endpoint labels of other samples) | reference for how much is predictable from the condition alone; not available for a new condition |
| final e / d2 of the endpoint | yes | reproduces the label by construction |
| off-atom fractions; same training image as the exact field | yes | endpoint descriptors |
