# Paper B: incremental value of the field-error signal over the nearest-neighbour baseline

Script: `scripts/paperB_incremental.py`. Target: off-atom label (endpoint d1/d2 >= 1/3; not the key `label`, which is the class). Every predictor at noise level sigma_i uses the predictive anchor (nearest training image of D(x_i)), so nothing uses the endpoint.

* Baseline: log dD_i. Candidates: rhoA_i, radA_i, causal late contraction C_i^(s0) = sum_{j=j0}^{i-1} (1 - (rhoA_j + rhoA_{j+1})/2) log(sigma_j/sigma_{j+1}) from sigma_{j0} (grid 5.32, 1.92, 0.585) to sigma_i (the last interval ends at sigma_i, so only rhoA up to index i enters).
* Logistic regression, Newton-Raphson; CV fits carry a ridge of 1e-4 on standardised slopes (inert unless the classes separate). CV = 10-fold stratified x 20 repeats (fold seeds [20261121, r], r = 0..19); CV AUC = AUC of the pooled out-of-fold linear predictor of a repeat, mean over repeats.
* Delta AUC interval: 95% paired class-stratified bootstrap over samples (B = 2000) of the stored out-of-fold predictions, no refit, repeats averaged inside each resample. The refit check (fit on the resample, AUC on out-of-bag samples, B = 500) is in its own table.
* LR test: in-sample ML fits, chi2 with 1 df; where the MLE does not exist (complete separation, marked F) the p-value is Firth's penalised LR test. Holm: over all field-error tests of a model (rhoA, radA, C windows, truncated C); diagnostics are not in the family and show raw p.
* quad Delta AUC: the same comparison with a quadratic baseline (log dD, (log dD)^2).
* CV dLL: out-of-fold log-likelihood gain per sample (nats), bootstrap interval as for Delta AUC.
* 'C restricted to sigma >= 0.06': the C rows with sigma_i >= 0.05995 (grid value nearest 0.06, index 14), and the rows `C*_trunc`, where C is frozen at sigma 0.05995 and compared with log dD at sigma 0.0229, 0.00753, 0.002.
* History control (diagnostic, not in the Holm family): `Hist*` = the same trapezoid integral over the same window applied to log dD, tested over log dD_i; `C*|hist` = C tested over (log dD_i, Hist_i). C aggregates several noise levels while the baseline uses one; this separates the field-error content of C from the benefit of using the trajectory's history.
* Class-adjusted check: Firth LR test of the candidate given log dD + class dummies (the class is known at sampling time and off-atom rates differ by class).
* Resolution: the OOF bootstrap resolves Delta AUC of order 1e-4 (the placebo (log dD)^2 has intervals slightly below 0), so an interval above 0 for a gain of 0.002 means a real but small gain; the refit interval is wider and is the more conservative one.
